# OpenStream support

## Published release

The public v1.0.1 GitHub release contains an Android APK and Windows OBS plugin packages. The release notes identify that release as Windows-only. They do not list a Linux package. The repository's current Linux build instructions describe a source build, but they do not establish that a Linux release package was published.

The repository does not include a completed phone and OBS compatibility matrix. The published release's device, Android-version, and OBS-scene compatibility claims need verification against the actual v1.0.1 artifacts and real devices. See the [agent roadmap](agent-roadmap.md) for the required baseline and beta checks.

## Get help or report a bug

Use [GitHub Issues](https://github.com/YashasVM/OpenStream/issues) for setup questions and reproducible bugs. Include the app version, Android version and phone model, OBS version and host OS, the steps that led to the problem, and what you expected to happen.

Do not post APKs, logs, screenshots, network addresses, tokens, or personal information unless they are needed and you have removed sensitive details. See the [privacy page](privacy.md) before sharing diagnostics.

The repository has no public support email address or feedback form. GitHub Issues is the configured public support route. Do not use a public issue to report a security vulnerability; read [`SECURITY.md`](../SECURITY.md).
