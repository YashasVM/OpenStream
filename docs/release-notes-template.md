# OpenStream Release

Artifacts included in this release:

- `openstream-android-debug.apk`: Android app build with native SRT streaming enabled.
- `openstream-obs-windows-x64.zip`: Windows x64 OBS Studio plugin DLL.

Install the APK on an Android phone, extract the OBS plugin zip, and copy
`openstream-obs.dll` into the OBS Studio `obs-plugins/64bit` directory.
