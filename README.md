# OpenStream

*Dated: September 28, 2026*

Use an Android phone as a camera source in OBS Studio.

- `android/` — phone camera app (streams over SRT/Wi-Fi, build via `tools/build_android_apk.sh`)
- `obs-plugin/` — OBS Studio plugin + camera control dock
- `website/` — download/setup site (V1.0.1 APK, Windows plugin installer/zip)
- `tools/` — pairing/SRT probes, installers, 16 KB alignment check
- `tests/` — contract/behavioural guards

Downloads and setup: https://github.com/YashasVM/OpenStream/releases/latest
