# Security policy

## Reporting a vulnerability

This repository does not currently publish a security email address or a verified private reporting channel. Do not post credentials, pairing secrets, private network details, or an unpatched vulnerability in a public issue.

If GitHub shows a **Report a vulnerability** option on the repository's Security tab, use that private report. If the option is unavailable, the project owner must configure a private contact before users can send a confidential report. Until then, do not include sensitive details in a public report.

## Supported releases

The repository has no published security support window. The public v1.0.1 release is the latest release identified during this inventory. Its security maintenance status is not stated. Ask the project owner to define supported versions and response expectations.

## Scope

OpenStream includes an Android camera app and a native OBS plugin. The documented media path sends camera video and microphone audio over a local network to OBS. Treat device identifiers, local addresses, logs, and pairing data as sensitive when reporting a problem.
